\# LTVM (Local TTS Voice Modulation)

基于本地大语言模型（LLM）与 GPT‑SoVITS 语音合成技术的 AI 角色聊天助手。支持接入 NapCat 连接 QQ，提供全功能的 WebUI 管理控制台。



\## ✨ 功能特性

\- \*\*本地化运行\*\*：数据不经过外部服务器，保障隐私安全。

\- \*\*AI 语音交互\*\*：通过 GPT‑SoVITS 实现文本到语音的拟真合成。

\- \*\*情绪模拟\*\*：支持多情绪切换、语气渐变、呼吸间隙与交叉淡化，让语音更自然。

\- \*\*角色定制\*\*：可通过 WebUI 轻松设置角色人格、回复风格与提示词。

\- \*\*聊天管理\*\*：支持多会话管理、历史记录查看与一键删除。

\- \*\*日志监控\*\*：实时查看运行日志，方便排查问题。



\## 🚀 快速开始

\### 直接安装

1\. 下载最新的 `LTVM\_Setup.exe`。

2\. 运行安装程序，选择安装路径并完成安装。

3\. 双击桌面图标运行。



\## 🖥️ WebUI 使用说明

程序启动后会自动打开控制台窗口（或通过浏览器访问 `http://127.0.0.1:11500`）。



\- \*\*配置文件\*\*：设置 NapCat 地址、LLM 模型 API、TTS 服务地址、角色人格及情绪映射。

\- \*\*聊天记录\*\*：查看与管理所有会话，支持批量删除。

\- \*\*日志输出\*\*：实时查看系统运行状态。



\## ⚙️ 配置说明

在 WebUI 中配置完成后点击「保存配置」，程序会生成 `config.json` 文件并持久化设置。



\### 核心配置项

| 配置项 | 说明 |

|---|---|

| napcat\_ws\_url | NapCat 的 WebSocket 地址 |

| client\_base\_url | GPT‑SoVITS API 地址 |

| ref\_audio\_root | 参考音频根目录 |

| model\_dir | TTS 模型文件夹 |



\## ❓ 常见问题 (FAQ)

\*\*Q：为什么窗口打不开？\*\*

A：请确认已安装 Microsoft Edge WebView2 Runtime，或检查 `config.json` 中的 `webui\_port` 是否被占用。



\*\*Q：为什么只有「保存配置」按钮，没有配置选项？\*\*

A：通常是因为旧版 `config.json` 缺少字段。请删除程序目录下的 `config.json` 后重启。



\*\*Q：为什么没有自动启动 TTS？\*\*

A：请确认在 `config.json` 中 `auto\_start\_tts` 为 `true`，且 `tts\_start\_script` 路径正确。
