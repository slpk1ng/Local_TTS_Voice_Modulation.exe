情绪音频管理

定时任务（主动问候 / 例行消息）

支持间隔、每日、每周触发；可发送固定话术或让 LLM 以角色身份生成内容。总开关见「配置文件 → 定时任务与主动消息」。

节日 / 纪念日问候

每天在配置的时刻（greeting_check_time）自动检查并发送；用户生日会从「用户画像」中自动读取。

待办提醒

聊天中说出「提醒我…」即可自动创建（需在配置中开启待办功能）；此处可手动添加与管理。

表情包

每个子文件夹是一种情绪分类（可与 LLM 输出的情绪名对应）；「default」为兜底、「any」为任意情绪都可能随机抽取。总开关与触发概率见「配置文件 → 表情包」。

工具调用 (Function Calling)

LLM 可在回复时调用这些工具并把结果融入回答。总开关 tools_enabled 与命令类工具授权在「配置文件 → 工具调用」中。

知识库 RAG

上传文档后，角色回答时可自动检索相关内容注入上下文。需配置嵌入模型（默认 nomic-embed-text，可通过 ollama pull 获取）。总开关见「配置文件 → 知识库 RAG」。

用户画像

按 QQ 号记录用户偏好与生日；开启 profiles_auto_extract 后可由 LLM 自动从对话中提取。生日匹配当日时会自动送上祝福。

使用教程

欢迎使用 LTVM。以下为各功能说明（所有功能均可在对应页面独立开关与配置）：

1. 配置文件：修改所有运行参数；「功能开关」类配置分组可控制流式回复、主动消息、待办、表情包、多角色、工具调用、RAG、用户画像、动态上下文等功能的启停；支持配置的导入与导出。

2. 聊天记录：查看、管理与删除会话；支持单会话导出 / 导入（JSON）以及一键打包导出全部记忆。

3. 情绪音频：可视化上传/试听各情绪的参考音频与 asr.txt，可新建或删除情绪文件夹，保存后自动重扫。

4. 定时任务：自定义定时问候（间隔/每日/每周）、节日与生日自动问候、待办提醒管理。

5. 统计面板：消息量、情绪分布与趋势图表，实时性能监控（LLM/TTS 耗时、服务状态）。

6. 高级功能：表情包管理、工具调用（Function Calling）、知识库 RAG、用户画像。

7. 日志输出：实时查看机器人运行日志。

8. 使用教程：当前页面。

提示：主动消息（长时间未互动自动开口）、待办提取、画像自动提取等功能的详细参数都在「配置文件」对应分组中；每个功能必须开启对应开关后才会生效。
